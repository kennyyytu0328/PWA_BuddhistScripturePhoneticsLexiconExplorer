# 待釐清問題 — reader 單元

### Q-RDR-001 分頁方式
- 關聯：REQ-RDR-002、003
- 問題：規格說「經摺翻頁」「Scroll Snap 停靠」，但沒說一頁放多少經文。以手機（約 390×844）、20px 字、行高 2.8 估算，一個畫面約可放 200 字，全經約 300 字（含標點）只有一頁半。
- 選項：
  - A（建議）：一段一頁（9 頁）。每頁的直行數依段落長短而定，頁寬至少一個畫面；頁數少、留白多，符合 §6.5，也讓每頁能對應該段的白話參考。
  - B：經文連續排版，依畫面寬度切頁（約 2 頁）。
- 回覆：A（2026-10-17）

### Q-RDR-016 Noto TC 缺的字（Step 2 規劃時發現）
- 關聯：REQ-RDR-008、022
- 問題：以建置產物逐字檢查 Noto 字型涵蓋範圍（2026-10-17）：
  - 經文 121 字、白話參考 388 字：Noto Serif TC／Noto Sans TC 全部涵蓋。
  - DFB 釋義的「儞」（無明條）、「嚩」（蘇波訶條）不在 Noto Serif TC 子集版（SubsetOTF/TC），但在完整版 Noto Serif CJK TC（同一字體設計，原始檔 24MB）。
  - IAST 的 ś Ś ḥ ṃ ṣ ṇ ṭ（音標 `<rt>`）與 DFB 釋義中的 ś Ś ṁ ḥ ṇ：Noto Sans TC、Noto Serif TC 都沒有。REQ-RDR-022 要求「不退回系統字型」，只用 Noto TC 做不到。
- 選項：
  - A（建議）：襯線字改用完整版 Noto Serif CJK TC 原始檔產生子集（CSS 字族名仍為 Noto Serif TC）；另打包 Noto Sans、Noto Serif（拉丁字型，OFL）的子集，接在 font-family 第二順位，只補 TC 缺的拉丁擴充字母。REQ-RDR-022 改為「每個字都由打包字型涵蓋：漢字用 Noto TC，TC 缺的拉丁字母用 Noto Sans／Noto Serif」。
  - B：拉丁擴充字母允許退回系統字型（REQ-RDR-022 改為只要求漢字由打包字型涵蓋）。
- 回覆：B（2026-10-17）。「儞」「嚩」仍改用完整版 Noto Serif CJK TC 原始檔產生子集。

### Q-RDR-020 灰階判定基準（Step 3 盲寫測試時發現）
- 關聯：REQ-RDR-021、Q-RDR-012
- 問題：REQ-RDR-021 以「HSL 飽和度 < 10%」判定灰階，但 §1 指定的 stone-950 `#0c0a09`（RGB 12／10／9）飽和度為 14.3%（近黑色時 HSL 飽和度會放大），規格自相矛盾。
- 選項：
  - A（建議）：改以 RGB 三通道最大值與最小值的差 ≤ 10（0–255）判定灰階；stone-950 差 3、stone-900 差 5，琥珀色遠超出。
  - B：維持飽和度 < 10%，stone-950 列為例外。
- 回覆：A（2026-10-19）
