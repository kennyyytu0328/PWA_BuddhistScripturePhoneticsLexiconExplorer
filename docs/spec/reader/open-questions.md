# 待釐清問題 — reader 單元
> 2026-10-17 由 Step 0 需求登錄產生。每題附建議選項；回覆後併入 `requirements.md`。

### Q-RDR-001 分頁方式
- 關聯：REQ-RDR-002、003
- 問題：規格說「經摺翻頁」「Scroll Snap 停靠」，但沒說一頁放多少經文。以手機（約 390×844）、20px 字、行高 2.8 估算，一個畫面約可放 200 字，全經約 300 字（含標點）只有一頁半。
- 選項：
  - A（建議）：一段一頁（9 頁）。每頁的直行數依段落長短而定，頁寬至少一個畫面；頁數少、留白多，符合 §6.5，也讓每頁能對應該段的白話參考。
  - B：經文連續排版，依畫面寬度切頁（約 2 頁）。
- 回覆：A（2026-10-17）

### Q-RDR-002 白話參考的呈現位置
- 關聯：REQ-RDR-019
- 問題：§4-2 只要求區隔並標示「白話參考」，沒說放在哪裡、怎麼開啟。§1 又要求無頂底導航。
- 選項：
  - A（建議）：每頁一個小的「白話參考」膠囊按鈕，點開另一個底部面板（與名相抽屜不同面板），依序顯示白話、主題標籤、修持提示，標題為「白話參考」。
  - B：直接排在每頁經文後方（左側）的直行中，以分隔線與「白話參考」標題區隔。
  - C：本版不顯示。
- 回覆：A（2026-10-17）

### Q-RDR-004 多義項條目
- 關聯：REQ-RDR-014、015
- 問題：五蘊、空相、六根、四諦各有 2 個義項；AST 的 `sense` 指出經文採用哪一義。
- 選項：
  - A（建議）：列出全部義項，經文採用的義項排在最前並標示，各義項附 `usg`（如「術語」「名數」）。
  - B：只顯示經文採用的義項。
- 回覆：A（2026-10-17）

### Q-RDR-005 轉引連結的行為
- 關聯：REQ-RDR-016
- 問題：第一層轉引目標（如 觀自在 → 觀音）已收錄；第二層（觀音 → 五大明王、心經 → 般若心經）只保留文字、未收錄。
- 選項：
  - A（建議）：點擊已收錄的轉引目標，抽屜內容換成目標條目，並出現「返回」回到原條目；未收錄的目標顯示為一般文字、不可點擊。
  - B：轉引目標只顯示文字，都不可點擊。
- 回覆：A（2026-10-17）

### Q-RDR-010 字型子集範圍與釋義字型
- 關聯：REQ-RDR-022
- 問題：DFB 釋義用字遠多於經文，子集必須涵蓋所有會顯示的字；規格沒說抽屜釋義用哪種字型。
- 選項：
  - A（建議）：建置時從 AST、辭典、介面文字收集全部用字產生兩個子集；經文與 DFB 釋義用 Noto Serif TC（釋義橫排），介面標籤、`<rt>`、白話參考用 Noto Sans TC。字型檔（OFL 授權）放 repo。
  - B：釋義也用 Noto Sans TC。
- 回覆：A（2026-10-17）

### Q-RDR-011 直排標點的量測基準
- 關聯：REQ-RDR-007
- 問題：「字右上偏中」需要可自動驗證的標準。
- 選項：
  - A（建議）：Playwright 量測每個標點的字形邊界框：中心點落在字格右半、上半部，且與前一字同一直行；並截圖人工確認一次。
  - B：只做人工截圖確認。
- 回覆：A（2026-10-17）

### Q-RDR-012 stone 系色是否算「無彩色」
- 關聯：REQ-RDR-021
- 問題：§1、§6.4 指定 stone-950、stone-900 等，stone 是略帶暖色的灰（R≠G≠B），字面上不是純灰。
- 選項：
  - A（建議）：stone 系視為灰階；驗收以「飽和度低於 10%」判定，琥珀色只允許出現在 `<rt>` 與名相高亮。
  - B：改用純灰（neutral 系），需改寫 §1、§6.4 的色名。
- 回覆：A（2026-10-17）

### Q-RDR-013 效能量測條件
- 關聯：REQ-RDR-027
- 問題：FCP < 0.8s、60fps、CLS = 0 沒有指定裝置、網路與量測方式。
- 選項：
  - A（建議）：以正式建置（`pnpm build` 後 `vite preview`）在 Playwright Chromium 手機 viewport、無網路節流下量測：FCP 由 PerformanceObserver 取得 < 800ms；載入、切換音標、開關抽屜過程 CLS 總和為 0；60fps 由手動實機確認並記錄（自動化不穩定）。
  - B：以 Lighthouse 行動版預設（含 4G 節流）量測 FCP。0.8s 在節流下很難達到。
- 回覆：A（2026-10-17）

### Q-RDR-014 UI 的測試覆蓋率怎麼算
- 關聯：REQ-RDR-028
- 問題：目前 vitest 覆蓋率只統計 `scripts/`；UI 程式在 `src/`。
- 選項：
  - A（建議）：`src/` 的 hook 與邏輯以 vitest（jsdom）寫單元測試，覆蓋率範圍加入 `src/**`，行覆蓋率 ≥ 80%；驗收測試用 Playwright。
  - B：以 Playwright 收集瀏覽器端覆蓋率合併計算。
- 回覆：A（2026-10-17）

### Q-RDR-015 翻頁的緩動曲線
- 關聯：REQ-RDR-026
- 問題：§6.5 說轉場用 `cubic-bezier(0.19, 1, 0.22, 1)`，但 CSS Scroll Snap 的停靠動畫由瀏覽器決定，無法指定曲線；自己寫翻頁動畫又會失去原生 Scroll Snap。
- 選項：
  - A（建議）：翻頁維持原生 Scroll Snap（§6.1 已指定），不套用該曲線；曲線用於抽屜、面板與其他 CSS 轉場。
  - B：自製翻頁動畫以套用曲線（偏離 §6.1）。
- 回覆：A（2026-10-17）
